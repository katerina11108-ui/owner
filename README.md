# Neoiatria — сайт

Astro 4, статична збірка. Дизайн — Figma «Neoiatria Website», сторінка 01 Design. Специфікація — документ «Neoiatria — специфікація для розробки».

## Запуск
```bash
npm install
FIGMA_TOKEN=ваш_токен npm run assets   # фото й логотип з Figma → public/images
npm run dev                             # http://localhost:4321
npm run build                           # статика в dist/
```
Токен: Figma → Settings → Security → Personal access tokens (лише читання файлів).

## Структура
- `src/styles/tokens.css` — усі токени з Figma-змінних (кольори, відступи, радіуси) як CSS custom properties.
- `src/styles/global.css` — типографічна шкала (десктоп і мобільна), контейнер, секції, мобільні каруселі (`.m-scroll`).
- `src/lib/icons.ts` + `Icon.astro` — 45 векторних іконок з Figma, колір через `currentColor`. Текстові символи-стрілки не використовуються.
- `src/components/` — спільні компоненти: Header, MobileMenu, Footer, StickyCTA, Button, SpecialistCard, EventCard, Trust, Founders, Formats, FAQ, CTAPrefooter, PsychiatristBanner.
- `src/components/home/` — секції головної.
- `src/data/` — контент у структурі під Sanity: `site` (Settings), `specialists` (17 реальних фахівців з таблиці), `directions`, `content` (заперечення, відгуки, FAQ, події, офіси). `filters` — групи фільтрів каталогу, що рахуються з полів фахівця; `methods` — довідник методів для профілю.
- `src/pages/specialists/` — `index.astro` (пошук) і `[slug].astro` (профіль, по сторінці на фахівця).

## Готово
- Головна — десктоп і мобільний, звірено з макетом.
- 404.
- Запис `/booking/:slug?session=N` — крок «Ваші дані» з підсумком запису і вибором формату; `/booking/confirmed` — «Запис підтверджено» (сюди Altegio повертає після оплати). Поки `settings.altegioWidget` порожній, форма працює як заявка: адміністратор узгоджує час і оплату.
- «Поставити питання» — модалка в профілі (`#ask`), стани «форма» і «надіслано».
- Блог `/blog` (рекомендована стаття, фільтр за рубриками, сітка карток, підписка) і стаття `/blog/:slug` (шаблон із блоків: лід, підзаголовок, абзац, цитата; «Читайте також»).
- Події та матеріали `/events`: найближчі події, подкаст (`#podcast`), лекції / курси / PDF із фільтром за типом (`#materials`).
- Про центр `/about` — десктоп і мобільний; засновники, довіра, формати й події — ті самі компоненти, що на головній.
- Пошук спеціалістів `/specialists` — десктоп і мобільний. Фільтри: фахівець, запит, метод, формат, тип сесії, мова, ціна; усередині групи — «або», між групами — «і». Стан фільтрів і сортування — у query-параметрах (`?request=anxiety,trauma&format=online&max=2500&sort=price-asc`), тож посиланням можна ділитися. На мобільному — прилипла панель, обрані фільтри чипами, фільтри в нижній шторці (Esc, фокус, блокування прокрутки). Порожній результат підказує, який фільтр прибрати. Картки показуються по 6, далі — «Показати ще».
- Профіль фахівця `/specialists/:slug` — десктоп і мобільний: перший екран, картка запису (вибір типу сесії), «Про мене» зі згортанням, запити, «З чим не працюю», методи, перша сесія, освіта, відгуки, умови, CTA перед футером, мобільна прилипла панель запису. Блок без даних не показується.
- Хедер, мобільне меню (фокус, Esc, блокування прокрутки), прилипла кнопка на мобільному, футер.

## Форми
Запис (`booking`) і питання (`question`) відправляються в Netlify Forms (`src/lib/forms.ts`). У Netlify треба один раз увімкнути Forms → Enable form detection і додати email для сповіщень. Локально (`npm run dev`) відправка не працює — форма покаже помилку з посиланням на Telegram, це очікувано.
